# ADR-0005 — EXT-001 : un asset externe partout si le style colle

- **Statut :** approuvée
- **Date :** 2026-11-19
- **Approuvée par :** David, HL-538 7-2949

## Contexte

Les packs externes (Kenney) peuvent contredire la consigne des planches de David, cibles depuis le 19/11 (relecture 7-2948, point 4).

## Décision

« Partout si le style colle. » Un asset externe peut remplacer un élément de planche si l'agent juge le style compatible ; preuve à fournir : un côte à côte avec la planche.

## Alternatives

- Assets externes réservés aux jeux sans planche : écartée par David.
- Sons et polices seulement : écartée par David.

## Retour arrière

Un asset externe garde sa fiche et sa provenance (`provenance.external`) ; le retirer d'un jeu revient à rétablir l'usage de l'élément de planche dans le lock, sans toucher au catalogue.
